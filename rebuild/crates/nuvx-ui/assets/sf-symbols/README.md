# SF Symbols

Apple SF Symbols glyphs, exported as SVG from the owner's SFStudio library (https://github.com/lylicht/SFStudio,
commit in SOURCE-COMMIT) with tools/export_sf_symbols.py. Apple licenses SF Symbols for Apple platforms; using them on
Android, desktop and the web is the owner's decision (2026-11-17, reaffirmed 2026-11-22). Do not edit by hand:
re-export with the script.
