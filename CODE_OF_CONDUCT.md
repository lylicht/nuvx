# Code of Conduct

## Our standards

Everyone participating in VYRAL is expected to be respectful and constructive. Harassment, discrimination, personal attacks, doxxing, and deliberately disruptive behavior are not acceptable. Critique ideas and code without attacking people.

## Reporting

Report conduct concerns privately to the repository maintainer through GitHub. Do not include security vulnerabilities or private personal information in a public issue.

The maintainer may remove content or restrict participation when needed to keep the project and its community safe. Reports will be handled as privately as reasonably possible.
