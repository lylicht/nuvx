# Security policy

## Reporting a vulnerability

Do not publish an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when it is enabled. If it is unavailable, contact the repository maintainer privately through GitHub at [syrrnight](https://github.com/syrrnight).

Include the affected component and version or commit, platform, reproduction steps, and impact. Remove credentials, tokens, personal data, and other secrets from reports and logs.

## Scope

Reports about VYRAL code, packaged dependencies, authentication, data handling, and release artifacts are welcome. Third-party upstream issues should also be reported to their maintainers when the defect is outside VYRAL's integration.
